Приложение для устройств с YaOS

Это работает для Станции Дуо Макс, ТВ Станций и телевизоров с YaOS. Для личного использования без публикации есть более простой путь: раздел «Мои приложения» на устройстве — сканируете QR-код, добавляете свой APK, после автоматической проверки приложение доступно для установки


проект на Kotlin (Android, собирается в APK и ставится на Дуо Макс через «Мои приложения» в Я.Диалогах). Что он делает: в заданные даты и время выводит на весь экран видео с музыкальной дорожкой (обложка res/raw/greeting.mp4) и текст поздравления поверх. Один нюанс честно скажу сразу: голосом Алисы из стороннего приложения она не говорит — этот публичный API отсутствует, поэтому «озвучку» оставляем либо музыкальной дорожке видео, либо параллельному сценарию в «Доме с Алисой»
